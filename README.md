# Gmail Inbox Organizer

A small, human-written demo project for a conversational Gmail helper.

The idea is simple:
1. Connect a Gmail account.
2. Ask in plain language to archive, label, move, or delete selected messages.
3. Show exactly what will be changed or deleted.
4. Require an explicit confirmation for destructive actions.

This repository is intentionally a front-end demo. It does **not** contain real OAuth secrets or call the live Gmail API.

Open `index.html` locally to try it.
